# Div-Racer
A fun Minigame where you can bet wich "car" get on the Finishline first
---
## Controls
- The 'Tick' button show one tick, so one calculation
- 'start' and 'stop' should be self-explanatory
- The Slider is to controll the tickspeed, normaly it's 900ms per tick, one tick - 900ms - one tick
- You can only effect the tickspeed when it isn't running, so klick 'stop', change the speed and then click 'start'
## Bets
- You can click the buttons '1' - '5' to bet on the cars 1-5 (from top to bottom || red - yellow)
- Each Player can bet on 1 Car, so the code is Counting the Player number automaticly up
- At the end the right bets will be shown, so remember your Player-Number!
